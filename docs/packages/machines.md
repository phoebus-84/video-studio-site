# machines

> The operator's machines, declared once in a library file: how SSH reaches each, what each is for (Remotion, Blender, ComfyUI, heavy CPU or GPU work) and in which order to use them. Says where to run a role and reaches a service on a machine's loopback through a health-checked tunnel. Optional at run time: without the file, everything runs here as before.

## Using it outside this project

This is a reusable tool. It does not know what an episode, a series or a
pipeline is, and it must never learn — `npm run check:boundaries` fails if
it grows a dependency on `studio/*`. Studio-specific integration lives in
[`studio/agent`](../studio/agent.md).
