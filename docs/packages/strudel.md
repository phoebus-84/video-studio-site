# strudel

> Music written as Strudel code, checked without a sound and rendered offline by the pinned Strudel engine in a headless Chrome: parts, stretches of cycles, tails, seamless loops, stems, and measurements of what was made. Optional at run time: without a Chrome, everything else works. AGPL-3.0-or-later, as Strudel is.

## Using it outside this project

This is a reusable tool. It does not know what an episode, a series or a
pipeline is, and it must never learn — `npm run check:boundaries` fails if
it grows a dependency on `studio/*`. Studio-specific integration lives in
[`studio/agent`](../studio/agent.md).
